# ComServ Africa Point of Sale System

## System Overview
Complete POS system for ComServ Africa PBC with dual-user roles (Admin & Teller) built in VB.NET with MS Access 2007+ database.

## Features

### Admin Functions
✓ Add and manage products with specifications
✓ Set and update prices
✓ Manage stock levels
✓ View sales reports
✓ Customer management (blacklist/whitelist)
✓ Promotion management

### Teller Functions
✓ Process sales transactions
✓ Verify stock levels
✓ Handle returns
✓ Generate quotations
✓ Print receipts with company details
✓ Apply promotions

## System Requirements
- Windows 7 or higher
- .NET Framework 4.5+
- MS Access 2007 or higher
- 500MB free disk space

## Installation
1. Extract the ZIP file
2. Run the installer: ComServPOS_Setup.exe
3. Database will be installed automatically
4. Launch application and log in
